# Native contact spike run records

Each child directory is one bounded local run attempt. `attempt_01_superseded` preserves the initial runner's mapping failure and its explicitly superseded blank plot. `attempt_02_mapping_fix` is the single authorized rerun after separating each native body-local point ID from its unique combined export row ID. The fixed geometry, material, loading, penalty, radius, thread, step and wall-time parameters are unchanged.

Use only a case's `summary.json` status and its `point_steps.csv` / `step_metrics.csv` rows as recorded evidence. A state/force image is written only when actual point-state rows exist. The Julia-native contact force density, its own-volume force conversion, and native bond-only comparison are described in the case summaries.

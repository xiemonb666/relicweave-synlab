## 1. 项目核心目标

### 1.1 一句话定义（文档原文）

> "我们研究低质量部分观测下的碎片邻接候选检索。系统从真实碎片照片出发，在混合碎片库中提出值得人工核验的邻片候选；证据不足时，提出有成本约束的补采建议或停止推荐。比赛交付可运行、可恢复的辅助系统，研究交付能够经独立对照验证的方法机制。"

来源：§文首/p3

### 1.2 科学问题与要解决的"根问题"

| 维度 | 文档表述 | 出处 |
|---|---|---|
| 科学问题 | 低质量、**部分可观察**输入下的碎片**邻接候选检索**（不是全自动复原） | p3, p98 |
| 已证实的瓶颈 | 现有强证据只能回答"像不像／是不是同一器物"，**不能稳定区分"是否直接相邻"**；36/142 miss 中 14/36（38.9%）Top 阻挡者为同器物非邻接 | p953（E09） |
| 明确的负结论 | 换更复杂的排序/融合模型、Same-Vessel 多任务、global max-pool、三类 local relational 表示（bilinear / cross-attention / Sinkhorn-OT）**均未突破** | p960（E10）、p968（E11）、p975（E12） |
| 下一步信息源 | Gate A 只把"**更直接的邻接 / 断裂面证据**"列为下一优先信息源；不决定该证据是 1D 还是 2D，**也不授权硬件采购** | p1066、p954 |
| 待验证的差异点 | 部分可观察输入、大图库多邻片、拒识与真实成本证据更新 | p340 |
| 反捷径纪律 | 单个核心 metric 必须先算 random floor 与 attainable/oracle ceiling 再冻结门（因曾出现 Corr R@5≥0.80 数学上不可达） | p982、p986（E13） |

## 2. 评价指标与验收门槛

### 2.1 单一评测公式（完整分母）

设 `q` 为 query，`G` 为冻结图库且**排除 q 自身**，`N_G(q)` 为全部**库内**历史真邻片，`C_M` 为初检池，`T_K` 为精排前 K：

| 指标 | 公式 |
|---|---|
| Hit@K | `1[T_K ∩ N_G ≠ ∅]` |
| CovRecall@K | `|T_K ∩ N_G| / |N_G|` |
| any@M | `1[C_M ∩ N_G ≠ ∅]` |
| PoolCov@M | `|C_M ∩ N_G| / |N_G|` |
| ConditionalCov | 分母 `|C_M ∩ N_G|`，**只作池内诊断**；零池正例为 NA 并计 `pool_miss` |

来源：§2.2.1 单一评测公式与完整分母/p108

### 2.2 分母与统计规则（硬约束）

1. **有邻片主指标包含拒识**：给"拒识前排序"及"拒识时列表为空"的 `EffectiveHit` / `EffectiveCov`；接受后 Hit **仅在接受子集**计算并给接受率。
2. **聚合顺序**：先按母体内预注册 query 平均，再对**独立母体等权宏平均**。
3. **重复观测不增加独立样本**；无邻片单列风险。
4. **GT 资格在看模型排名前冻结**；所有产品提交与采集、QA、导入、闭合失败**仍保留在工作流分母**。
5. `mate-absent` 查询**不进入** Hit 与 CovRecall 分母。
6. 误导率 = 无邻片查询被接受推荐的数量 ÷ 无邻片查询总数；接受后风险另用**被接受查询**作分母，两个指标不能混用。
7. R1 误排 = Top10 中 R1 数量 ÷ 有效候选位数量；另报"R1 排在第一名或首名 R2 之前"的查询比例；UNKNOWN 位单独统计且**不强当 R1**，定义写入 `metrics_contract`。
8. 未运行填 `NOT_RUN`，不适用填 `NOT_APPLICABLE`，证据不足填 `NOT_ESTABLISHED`。

来源：§2.2.1 p109-p110 / §2.2 p106 / §A9.1 p329-p330

### 2.3 内部指标合同（数值门槛）

| 指标 | 定义与适用范围 | 目标或判定方式 |
|---|---|---|
| any@50 | 有邻片查询中至少一名真邻片进入初检 50 池 | **正常质量内部目标宏值 0.95**，连同区间报告 |
| Hit@10 | 前 10 中至少一名库内真邻片 | **比赛准备目标正常质量宏值 0.90，95% 下界 0.85** |
| 低质 Hit@10 | 日常低质查询对清晰库，独立母体 | **内部目标 0.85**，达不到则缩小适用范围 |
| CovRecall@10 | 前 10 找回库内真邻片的比例 | 与 Hit 单列，**不低于冻结强基线** |
| 新方法主比较 | 同查询同库相对验证集选出的强基线 | **开发起点为增益 3 个百分点且对象簇 CI 下界大于 0** |
| 干净性能守卫 | 新方法相对同池强基线 | **下降不超过 2 个百分点**，阈值先冻结 |
| 无邻片误导 | mate-absent 查询被接受推荐的比例 | **目标不超过 5%，95% 上界目标不超过 10%** |
| 有邻片接受覆盖 | mate-present 中被系统接受输出的比例 | **目标至少 80%**，不能靠全拒绝换低风险 |
| 现场流程 | 新查询采集到结果的完整彩排 | **20 次至少 19 次完成**，仅作为彩排目标 |
| 工作流价值 | 包括拍摄、补拍、检查的总任务时间 | **中位用时减少 30%** 为内部目标，正确性不恶化 |

## 3. 训练 / 评测路线

### 3.1 为什么"合成预训练 + 真实微调"

文档给的**不是**泛泛的"数据不够就合成"，而是一条**归因纪律**：

> "如果一个机制只在合成 clean 数据提升，而在严重退化、hard negatives 或真实微调后消失，则保留为负结果或低优先级……反之，如果机制在合成环境中能被严格归因，并在真实低质量碎片上保留方向一致的增益，才升级为论文核心候选。"

来源：§A12.11/p381

| 合成平台角色 | 主要回答的问题 | 允许得出的结论 | **不能替代的证据** |
|---|---|---|---|
| 大规模预训练 | 能否先学器型、断口互补、纹样连续和关系检索先验？ | 合成预训练是否减少真实微调所需样本、提高收敛或鲁棒性 | **不能证明真实手机数据已经可用** |
| 机制验证 | 某新机制在严格受控下是否有可归因增益？ | 可筛掉无效创新，定位机制在哪类退化/难例有效 | **不能只凭合成增益宣称真实世界 SOTA** |
| 退化实验 | 各种损失分别造成多大性能下降？ | 敏感度曲线、临界质量、失败类型 | **不能假设程序退化与真实退化分布一致** |
| 数据充分性 | 是数据量、质量还是算法上限不足？ | 建立 N×Q 曲面和最小数据量估计 | **不能把合成 N 直接换算成真实 N** |
| 采集/重建反推 | 提升哪种观测质量最值得？ | 把模型侧敏感度转成采集优先级和验收指标 | **最终硬件收益仍须同片真实对照** |

来源：§A12.1/t027

**搭建 8 步顺序**：① 相机节点桌面通电，用真实断口验证清晰度、分辨率、稳定采图和 SDK → ② 固定框架、承载轴承和软托架，手动检查全行程无干涉 → ③ 单轴驱动空载回零及低速运动，确认复位禁能、限位和急停 → ④ 加 Z 滑架、防坠和线束，带代表载荷检查运动与温升 → ⑤ 加分区白光，测试曝光条纹与普通/偏振配对 → ⑥ 与电脑联调到位、稳定、采图、QA、文件提交和下一动作 → ⑦ 与 B 同片比较手机和板载相机，冻结模型比较任务及总成本 → ⑧ 基础台通过后，再增加第二节点或前后俯仰，并逐轴重复验收。

来源：§C11/p582-p589

**故障恢复要点**：相机不识别先查模组 A/B 版本、排线方向、供电和厂商镜像，再查设备树和驱动；色偏先确认 ISP 与曝光白平衡；blur 先检查焦距、振动和快门，**不能一律换高像素模组**；运动丢步先降加速度并核摩擦、负载、电流及供电，**不能提高微步后宣称精度提升**；Z 断电下滑必须先解决机械保持；高光仍在时调整灯位、柔光、偏振轴和相机角度并保留残余记录；透明罩反光时让镜头在舱内直接看样品，透明板不位于成像光路。来源：§C12/p595-p598

## 6. "合成 ≥ 扫描台"的要求：文档是否明确提出？

### 6.1 结论（直接回答）

**文档没有一句"合成数据必须覆盖或超过扫描台可得模态"的显式要求。** 本文对该问题做了全文检索（关键词组合：合成+覆盖/超过/一致/对齐/等价/同构/不低于、扫描台+合成、合成+扫描），命中的只有 **2 处**，且都与"覆盖度"无关：

- p381：机制只在合成 clean 提升、在真实微调后消失则保留为负结果；
- p397：附录 G 的 SY-Q0 至 SY-Q5 **仅用于本合成实验室**，不覆盖历史实验中的 Q 编号或已冻结 SPEC。

来源：§A12.11/p381、§A12.16/p397（全文检索未命中"合成必须覆盖扫描台模态"类表述）

### 6.2 文档实际给出的、最接近的 4 条"接口对齐"要求（可作替代依据）

## 10. 一页纸摘要

### 10.1 项目核心 5 条

1. **任务**：在**低质量、部分可观察**输入下做**碎片邻接候选检索**——从真实碎片照片出发，在混合碎片库中给出**值得人工核验**的邻片候选；证据不足时给出**有成本约束的补采建议或停止推荐**。输入＝整片 2D＋断口 2D＋质量；输出＝有序候选＋可追溯证据＋待核验状态＋补采/停止原因。（p3、p98）
2. **明确不做**：全器物自动复原、自动粘合、自动翻转脆弱样本、生成缺失纹饰、工业计量；2D 缺可靠几何时不强行输出物理接触坐标。（p100）
3. **指标合同**：`any@50` 宏值 0.95；`Hit@10` 宏值 0.90（95% 下界 0.85）；低质 `Hit@10` 0.85；新方法增益 ≥3pt 且对象簇 CI 下界 >0；干净性能守卫下降 ≤2pt；无邻片误导 ≤5%（95% 上界 ≤10%）；有邻片接受覆盖 ≥80%；工作流中位用时 −30%。统计单位为**母体簇配对双侧 95% 区间**；零事件单侧上界 n=20 → 13.9%。（t005、p106、p1562）
4. **路线**：**宽随机合成预训练 + 真实统计校准 + 少量真实微调**三级策略；合成的唯一合法用途是"可控实验仪器"（预训练/机制筛选/退化干预/N×Q 诊断/采集反推），**只有机制迁移到独立真实数据才能写入真实能力主张**。（t027、p384、p394）
5. **当前事实（不可误读为已完成）**：手机加转盘真实效果**未验证**；DIY 台**未采购、未搭建、未验证**；Gate B **LOCKED**；FractureScan **NOT PURCHASED**；R2c-0 **FAIL**；H690 公开数据邻接 GT **严格为 0**。（t003、p875、p1129、p894）

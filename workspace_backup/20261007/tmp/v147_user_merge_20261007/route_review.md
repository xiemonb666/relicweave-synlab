# V1.47 路线审查

**结论：方向接受，关系与评测合同需修订，实施和扩容延期。** 第2章把“观测碎片 → 排序的R2直接历史邻片 → 独立排序的R1同器物非邻片 → 器物成员集合”作为长期路线，逻辑上成立；也把证据卡、UNKNOWN/拒绝、补采和停止写进输出边界。whole-vessel membership recovery 是合理的远期任务扩展。A6.15–28目前仍标为研究候选，这个状态应保留。

**本次不应据此开启开发或宣称实验进展。** 按任务提供的现况，PG约25–35%，moving-front仍有 fieldrc/return_code 接口不一致且没有重试；VF约30–40%，当前只有原生CAD来源核对，Objectivity来源核查属于PG-Frag；A12约30–40%，没有 physically-qualified pack。缺少物理合格pack只阻止依赖该pack的物理合成/预训练主张；若已有合格真实观测与闭合成员GT，后续真实数据上的静态/关系上下文实验资格不应被它阻止。当前closeout仍不加新开发、数值或实验声明。

## 应保留的路线

- 第2章2.0–2.2清楚区分R2、R1与数据库范围的成员恢复；清晰样本允许传统方法胜出，并要求退化、用户价值和论文主张各有证据。
- A6.16明确“R2不传递”，A6.17保留Scalar Feedback作为最小基线，A6.19要求预测边可撤销并带来源，A6.21设置Oracle/predicted/corrupted关系的停止门。
- A8 EXP10–12覆盖退化曲线、闭合母体上的集合任务和关系错误传播；A12.21–23也正确要求TruthPack离线、合成收益最终由真实域检验。
- B2.3把成员集合闭合与R2关系闭合分开审计。这一分离应保留。

## 必须修订的关系语义与权限

**精确冲突：A6.16写“最终 A—C 是 R1、R2 还是 UNKNOWN，仍要由直接接触证据和历史邻接真值判定”；A6.15表又把R0/R1/R2/UNKNOWN写成一个posterior，并在R2 Local Memory中存pose/gap/contact和source_id。** 这会让离线真值、预测证据、无标签三者混在一起，且source_id或pose可能成为泄漏通道。

将真值本体与模型的知识状态拆开：

- 已闭合、已标注的物理关系类为R0、R1、R2；UNKNOWN是标签缺失、证据不足或拒绝状态，不是第四种物理关系。
- 真实same-vessel是等价关系，因而真值上具有传递性；R2是同器物关系中的直接历史邻接子关系，不传递。预测R1边保持软分布，不能因图连通就硬推全组同器物。
- 仅在关系真值可判定时，约束 P(R2) ≤ P(same-vessel)，并使 P(R2)=P(same-vessel)·P(historical-adjacency|same-vessel)、P(R1)=P(same-vessel)·P(known-not-adjacent|same-vessel)。历史邻接未闭合时不能用“没有R2边”补成R1，必须保留UNKNOWN。
- 在线模型只从允许的照片、合格测量、质量和模型预测关系估计后验；绝不读取motherID、GT pose、历史邻接真值或TruthPack。M_R2中若保留pose，应明确是预测的pose_hat及其不确定性；source/provenance可用于审计与去相关，但身份键不得进入模型特征。
- A6.19/A6.20允许R2 belief由0.82降到0.41或改为UNKNOWN；这只是模型信念的版本化修订。历史真实R1/R2不能因新候选进入而互换，除非新的GT审计/版本更正或新的碎裂事件改变了适用叶片集合。保留证据、旧belief、变更原因和版本链。

A6.15的posterior/校准量也应指经过冻结开发集校准的模型信念，而非单边的“置信区间”。校准器版本、适用质量域、OOD状态、分关系校准和拒判阈值应随模型保存；主结果需同时给覆盖—风险。接触核验只能在实际合格的3D/量测可得时作为额外证据，不能把不可比较或未观察到当成反证。

## 必须增加：same-vessel与same-style的可辨识性门

**涉及条款：第2章Level 2/A6.18的材质、壁厚、纹样、器型先验与Vessel Memory，以及A12.22可控制的器型/材质/纹样。** 这些特征能支持候选排序，但在同模具、同批次或反复制造的相似器物间，不保证能识别“同一件物理器物”。若两个候选在允许的观测下可交换，模型没有信息依据选出正确mother；正确系统行为应是保留候选或拒判，而不是让GT身份标签逼出确定答案。

加入身份可辨识性审计：测试库必须有同类型、同材料/装饰/制造批次但属于不同实物的same-style hard negatives；按物理器物隔离训练、开发与确认集，并单列同批次/同模具压力组；屏蔽motherID、袋号、背景、会话、seed和资产命名。对经双盲专家/证据复核仍不可由当前观测区分的候选，定义歧义组或拒判评价，报告覆盖率—风险和可辨识子集表现。风格/材料只能作为先验，不能作为成员身份的证明。陶器生产研究记录到同一地区跨时期的稳定黏土来源，说明材料相似可跨越多件器物；它支持加入这类hard negatives，而不证明单件身份可由材料唯一确定。[npj Heritage Science研究](https://www.nature.com/articles/s40494-025-01667-1)

## 指标分母与闭合范围

**涉及条款：第2章2.2.2的precision/recall/F1公式和“只有member闭合母体进入主评测”，B2.3的“缺失实物去向已记录”，以及A12.22的episode。** 公式没有规定空集合；同时，Level 3本身定义为相对于冻结图库G的成员恢复，所以member closure必须指向明确的gallery snapshot。

- 定义 V_G(q) 为冻结图库G中属于q这件器物的已登记成员，不含q；闭合性是“该快照中所有候选条目的成员归属已知”，不是要求把原器物所有遗失或未入库碎片都找回来。物理失片情况可记在provenance中，但不能无故把数据库范围任务改成完整物理复原。
- 对每个query分别处理空集合：若V_G非空而预测空，Recall=0、Precision未定义、F1=0；若V_G空而预测非空，作为mate-absent/no-member false acceptance风险计；若两者都空，应计为正确空结果/覆盖，不把未定义P/R/F1设成0或1。报告成员存在与不存在子集。
- 另分 closed-snapshot 主结果与 partial/open-world诊断；未闭合项目不进closed-set P/R/F1，但仍记在全工作流分母及资格排除率中。
- 按每个独立物理器物内query先平均，再在独立器物/母体簇间等权宏平均；重复query、碎片、视图和episode不是独立样本。若多个器物共享一生产批次/来源，确认区间按更高层来源簇处理。
- 保持B2.3关于member closure与R2 closure分开：membership GT足以评成员集合时，不要求已穷尽每条断裂接触边；反过来，R2边闭合也不能替代成员归属闭合。

## Oracle与腐化测试需要匹配的控制

**涉及条款：A6.20 T1、A6.21“Oracle-R2上限”、A8 EXP12的Oracle→Predicted→Corrupted序列。** GT-R2上下文应改名为“特权上下文诊断”，它不是严格的信息论上限；上下文可能泄漏器物身份，而且增益也会受邻片数量、质量和候选访问条件影响。该臂只在离线评测器内读取GT。若作为teacher-forcing训练诊断，单独标记，绝不称作部署结果。

保持q、gallery、候选池、context条数/可见字段、检索/计算预算完全相同；GT-R2之外增加按度数、质量和source来源匹配的打乱邻片控制，并在可行时加入等条数GT-R1上下文控制，以辨明收益究竟来自接触关系还是“给了同器物成员提示”。模型、候选生成器和线上路径不得访问GT。若Oracle臂不增益，按计划暂停；若只在Oracle存在时增益，也不能升级为线上机制。

**A6.20/A8 EXP12目前只列0/5/10/20/30%腐化，没有定义分母或无边端点。** 错边率要分类型和分母：真R2中的漏边率、检索候选中的假R2数/率、R1↔R2交换、错same-vessel边、低质量边、同一照片/重建派生的相关重复边；不要用全图库N²负边总数作唯一FP分母。0/5/10/20/30%可保留为压力阶梯，但“现实”率须从冻结、独立母体上模型预测边的真实错误率估计，不能预先称某档现实。加入无R2 seed/空memory端点（应退回静态基线）和边全缺失情形；报告覆盖与错误成员注入，而不只报R1 Hit@K。若实际模型错误强烈按质量/类别/来源相关，合成腐化应重放这种相关结构，而非独立随机翻边。

## 退化曲线应分观测损伤与物理改变

**涉及条款：第2章2.2.2固定同GT的D0→Dn、A6.26的D0–D5语义、A12.21同关系GT下的wear/chipping/erosion轴。** “历史R2标签固定”与“当前贴合/可见性变化”并不矛盾；但真实物理移除材料可能破坏现有接触面、产生新的叶片或新的碎裂事件，不能把它和纯观测变化放在同一条固定拓扑退化轴里。

分别发布两种paired实验：
1. 固定碎片与历史关系GT，仅改变观察条件（遮挡、模糊、图像噪声、可控点云dropout/伪点、视图缺失）；该轨道可直接比较同一物理世界上的观测鲁棒性。
2. 物理磨损、材料移除、真实新崩口或二次断裂；保存parent/child和event lineage，保留历史R2事实，同时按新事件重算current_fit_valid、evidence_visible和新叶片关系。此轨道的真值依事件和发布版本，不假设拓扑不变。

A12的31轴本身是带操作参数、实测量和calibration status的软件注册表。只有有独立物理量测映射的轴才可把强度级称为“轻度/严重物理磨损”；未校准轴称recipe/合成扰动级，D5真实域单列作确认，不能把合成等级等同于真实年代或实际材料损失。

## 收敛到可执行的最小门与资源约束

A6.17的B1 Scalar Feedback及A6.21的等预算思想值得保留；但现在的B2–B5、双记忆、假设集、Vessel latent、Graph rereread、缺失槽和多损失池，加上EXP11多类set/graph基线、EXP12多机制比较，作为候选池太宽，不能同批全部实现或解释。

建议只按门推进，不在本次closeout开启：

1. 真实数据资格门：真实静态/关系上下文实验需要合格真实观测、冻结gallery及闭合成员GT；Oracle-R2臂另需独立闭合的R2真值。same-style可辨识性、泄漏审计和线上输入allowlist也要冻结。synthetic physically-qualified pack只作为物理合成、物理退化或合成预训练主张的门槛，不是上述真实数据实验的通用前置条件。
2. 静态门：用现有最佳pairwise/检索器形成共同gallery shortlist，分别输出R2、R1候选与UNKNOWN/拒绝；冻结成员存在/不存在和工作流分母。
3. 上下文门：B1 scalar反馈是必须报告的最小基线；同时测离线特权R2及匹配打乱控制，固定相同候选池和预算。若匹配后的特权上下文无R1信息增益，先审计候选覆盖、上下文构造、GT闭合、指标功效和真实数据容量；仍未显示信号时按当前协议停止该分支/资源投入，不声称关系信息普遍不存在。若特权上下文显示增益，即使scalar没有增益，也允许把B2 latent作为唯一下一项最小替代，并与B1匹配预算，以检验scalar是否存在信息瓶颈。
4. 机制门：只有在B2相对B1/静态基线的增益可归因、且实测错误确实造成级联风险时，才继续比较一个soft/reversible memory候选；在实测误差率和无edge端点上检查其能否安全退回静态基线。
5. 论文/部署门：独立真实器物确认、same-style hard negatives、选择性风险和明确失败域都通过后，再决定是否升级方法主线。真实域无收益则保留为工程/合成基础设施结果；依赖物理合成或物理预训练的主张还须通过对应的物理pack验收。

硬件层面，GeForce RTX 5090官方规格为32 GB显存；项目目标机器另报48 GB系统内存，但V1.47明确承认尚未在该配置测吞吐。[NVIDIA规格](https://www.nvidia.com/en-us/geforce/news/rtx-50-series-graphics-cards-gpu-laptop-announcements/) 因此不能从峰值算力推断全gallery token bank/全图成对关系可常驻或按时完成。把搜索限制为每片预编码/缓存、query→gallery向量初检、固定Top-K局部token精排与有上限的受影响子图重读；避免N×N全关系/全token常驻。冻结K、局部token数L、迭代上限、单query P95时延、峰值VRAM/RAM、FLOPs/GPU小时；同时计入初检、几何核验、重读和失败/重试。A6.15 Step 0的“query和候选库生成Fragment Token Bank”需明确是磁盘/CPU缓存+按需读top-K，不是把全库局部token全部送入VRAM。FLOPs单独不代表同延迟/显存；比较时必须固定候选池并报告端到端资源。

## 新颖性与最终判定

A6.22拒绝“首次自回归/首次预测反馈”的表述是正确的。PuzzleFusion++明确描述了重复的片段对齐、合并和auto-regressive式迭代；SARe也描述了接触结构监督、几何验证可靠局部子装配，再对不确定片段重采样。它们不等价于本项目的R1 same-vessel检索，但足以说明泛化的“迭代反馈/错误边重读”不能单独当成新颖性。[PuzzleFusion++论文](https://arxiv.org/abs/2406.00259) · [SARe论文](https://arxiv.org/abs/2603.21611)

可能保留的贡献需更窄：在可辨识、闭合的同器物非邻接检索中，测试R2接触上下文是否提供超出强pairwise/静态同器物检索的增益；若能，在可校准预测误差下以UNKNOWN/拒判和可撤销belief控制级联风险。A6.28列出的独立真实域、强基线、消融、退化分层、库规模/成员数、失败案例应作为门槛，不预先承诺CVPR主线。

**最终建议：接受第2章的产品/研究方向；修订上述本体、权限、闭合、退化、Oracle和资源条款；A6.15–28/EXP10–12/A12.21–23继续作为研究候选与离线合同；本次closeout不开发、不跑新数值、不将无合格pack的阶段写成完成。**

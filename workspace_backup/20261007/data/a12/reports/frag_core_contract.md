## 1. 任务定义与 I/O 合同

### 1.1 任务的精确表述

- "我们研究低质量部分观测下的碎片邻接候选检索。系统从真实碎片照片出发，在混合碎片库中提出值得人工核验的邻片候选；证据不足时，提出有成本约束的补采建议或停止推荐。比赛交付可运行、可恢复的辅助系统，研究交付能够经独立对照验证的方法机制。"
  来源：§RelicWeave 项目完整方案/p3
- "主问题是给定真实可获得的观测、候选检查预算和误导风险，如何找回邻片并识别观察不足。输入包括整片2D、断口2D和质量信息；合格3D、可信上下文是可选增强。输出包括有序候选、来源可追溯的证据、待核验状态、补采或停止原因。"
  来源：§2 合并主线与边界/p98
- "我们负责把碎片邻接检索主线推进为可复现的模型和实验。当前数据入口是手机加转盘人工采集，真实效果尚未验证。先保留已有公开基线，用合格真实2D观察建立静态候选链，再研究局部互补、观察充分性、循环重读和候选条件补采。此方案不要求使用纯循环Transformer或纯CTM。"
  来源：§4 模型架构与实验实施/p119
- 比赛必做候选链 = "全库初检、局部精排、证据卡和版本日志"；论文主张需"同输入强基线及端到端公平对照"。
  来源：§2.1 比赛必须实现与论文需要证明/t004
- 当前实际采集方式与未证明项：手机加转盘人工采集为第一阶段；"我们尚未证明DIY台、主动补采、循环主干或强化学习有效，也未将它们记为已实现能力。"
  来源：§RelicWeave 项目完整方案/p4

### 1.2 任务属于哪几类：检索／匹配／组装／分类

| 任务成分 | 文档表述 | 出处 |
|---|---|---|
| 检索（主任务） | "在混合碎片库中提出值得人工核验的邻片候选"；"全库初检、局部精排" | §RelicWeave/p3；§2.1/t004 |
| 池内精排（检索第二阶段） | "对固定池精排做诊断，同时运行全库端到端" | §EXP02/p302 |
| 片对关系分类 | "片对的R0/R1/R2可以分类，候选之间允许多名R2" | §A4.4/p155 |
| 局部匹配（部分对应） | "部分对应可参考SuperGlue的未匹配机制，但先实现soft partial matching，不默认全局一对一" | §A4.5/p159 |
| 可靠性判别（接受／待核验／拒识） | "calibrate_output … 接受或待核验或不足，不证明不存在邻片" | §A2.1/t007 |

## 2. 评价指标全文

### 2.1 单一评测公式（2.2.1，原文引用）

> "q为query，G为冻结图库且排除q自身，N_G(q)为全部库内历史真邻片，C_M为初检池，T_K为精排前K。Hit@K=1[T_K∩N_G非空]；CovRecall@K=|T_K∩N_G|／|N_G|；any@M=1[C_M∩N_G非空]；PoolCov@M=|C_M∩N_G|／|N_G|。ConditionalCov的分母|C_M∩N_G|只作池内诊断，零池正例为NA并计pool_miss。"
> 来源：§2.2.1 单一评测公式与完整分母/p108

> "有邻片主指标包含拒识：给拒识前排序及拒识时列表为空的EffectiveHit／EffectiveCov；接受后Hit仅在接受子集计算并给接受率。先按母体内预注册query平均，再独立母体等权宏平均。重复观测不增加独立样本，无邻片单列风险。GT资格在看模型排名前冻结；所有产品提交与采集、QA、导入、闭合失败仍保留在工作流分母。"
> 来源：§2.2.1/p109

> "手算卡：真邻片B、C，初检仅B且Top10含B，any=1、PoolCov=0.5、Cov=0.5、ConditionalCov=1；不是全邻片找回。另测零正例池、多邻片、|G|<K、自身排除、UNKNOWN和拒识。"
> 来源：§2.2.1/p110

### 2.2 指标合同表（§2.2，逐行抄录 t005）

| 指标 | 定义与适用范围 | 目标或判定方式 |
|---|---|---|
| any@50 | 有邻片查询中至少一名真邻片进入初检50池 | 正常质量内部目标宏值0.95，连同区间报告 |
| Hit@10 | 前10中至少一名库内真邻片 | 比赛准备目标正常质量宏值0.90，95%下界0.85 |
| 低质Hit@10 | 日常低质查询对清晰库，独立母体 | 内部目标0.85，达不到则缩小适用范围 |
| CovRecall@10 | 前10找回库内真邻片的比例 | 与Hit单列，不低于冻结强基线 |
| 新方法主比较 | 同查询同库相对验证集选出的强基线 | 开发起点为增益3个百分点且对象簇CI下界大于0 |
| 干净性能守卫 | 新方法相对同池强基线 | 下降不超过2个百分点，阈值先冻结 |
| 无邻片误导 | mate-absent查询被接受推荐的比例 | 目标不超过5%，95%上界目标不超过10% |
| 有邻片接受覆盖 | mate-present中被系统接受输出的比例 | 目标至少80%，不能靠全拒绝换低风险 |
| 现场流程 | 新查询采集到结果的完整彩排 | 20次至少19次完成，仅作为彩排目标 |
| 工作流价值 | 包括拍摄、补拍、检查的总任务时间 | 中位用时减少30%为内部目标，正确性不恶化 |

来源：§2.2 内部指标合同/t005

### 2.3 宏平均／微平均、分母与排除情形

- 对象宏平均／微平均定义："对象宏平均先对每个母体的有邻片查询求均值，再对母体等权；微平均合并所有有邻片查询。mate-absent查询不进入Hit与CovRecall分母。误导率为无邻片查询被接受推荐的数量除无邻片查询总数；接受后风险另用被接受查询作分母，两个指标不能混用。"
  来源：§A9.1 指标手算与失败标签/p329
- R1 误排定义："R1误排可先定义为Top10中R1数量除有效候选位数量，并另报R1排在第一名或首名R2之前的查询比例。UNKNOWN位单独统计且不强当R1，定义写入metrics_contract。最终论文主指标数量有限，其他指标作为诊断。"
  来源：§A9.1/p330
- 指标手算例："手算例：查询Q有库内真邻片B和C，初检池只保留B，Top10未含B，则any@M为1、Hit@10为0、CovRecall@10为0；主失败为池内错排，次因是部分邻片池外。若Top10含B，则Hit为1、CovRecall为0.5，不能写全部邻片已找回。若B和C均池外，则主失败为全部池外。"
  来源：§A9.1/p328

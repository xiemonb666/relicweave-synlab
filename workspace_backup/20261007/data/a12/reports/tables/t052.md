**C4 机械布局与运动设计**

| 机构 | 建议起点 | 设计要求 |
| 旋转轴 | 低压双极步进＋同步带或联轴器，独立承载轴承 | 负载、偏心、跳动和回差实测 |
| Z升降 | 完整丝杆导轨模组，有效行程150至200mm | 导轨承受侧向力，不只买丝杆 |
| U近远轴 | 基础必配手动光轴导轨，约150mm，预留100至200mm适配 | 丝杆、刻度、锁紧、止挡；焦点与净空验收 |
| 俯仰 | 基础版锁紧支架，升级位置舵机＋支撑轴承 | 转轴靠近相机重心，不靠舵机轴单独承载 |
| 左右 | 横梁长孔或手动滑移，固定后登记 | 不作为基础版自动能力 |
| 样品托架 | 软垫三点托架，可更换 | 不压断口，不遮主要观察面 |

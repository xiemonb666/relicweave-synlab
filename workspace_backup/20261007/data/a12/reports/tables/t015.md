**A6.3 Evidence-Deliberative CTM：把“连续思考”改造成任务内的证据审议**

| CTM 改造层 | 本项目定义 | 与普通循环的区别 | 必须做的否定性对照 |
| Hypothesis State | 显式维护 Top-K 候选 belief、支持、反证和不确定性轨迹。 | hidden state 不再是唯一输出；候选排序可在每个 tick 被推翻或恢复。 | 静态 pair scorer；普通共享循环；等 FLOPs 非共享深网。 |
| Active Evidence Read | 每轮根据当前歧义从 Evidence Bank 读取最有区分力的区域／模态。 | 不是每轮无差别重读全部 token。 | 全量固定融合；随机读取；质量优先但不看候选的简单策略。 |
| Corrective Update | 允许高可信新证据修正旧状态，而非只累积。 | 显式区分 retain/write/correct。 | 残差累加；GRU；仅 scalar gate。 |
| Contradiction Channel | 支持证据和反证分离建模，并区分缺失／不可比。 | 强反证可以触发 hypothesis revision。 | 只有正相似度的 scorer；将 missing 当 negative 的错误对照。 |
| Dynamic Consistency | 利用多 tick 的证据轨迹判断是否收敛。 | 输出可依赖时间轨迹而非最后一帧 hidden。 | 只用 final state；简单均值历史。 |
| Adaptive Stop | 不确定、冲突高或 Top-K 不稳定时继续；收敛后早停。 | 思考步数由样本难度决定。 | 固定 1/2/4/8 tick 与等计算静态模型。 |

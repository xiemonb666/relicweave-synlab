**A12.10 数据量×质量×算法三维诊断：决定下一阶段资源到底投到哪里**

| 现象 | 尚可能的原因 | 下一干预 |
| 理想观测低分 | GT、可见性、可达性、表征、优化 | 逐项审计并同输入比算法 |
| 理想高退化低 | 信息损失、估计／分布错配 | 单因素及真实补采，不直接归给硬件 |
| 增加N有效 | 独立母体、曝光、训练量同时变 | 固定及收敛预算分列 |
| N平而质量有效 | 当前模型与范围的瓶颈候选 | 跨模型和真实配对再投入 |
| 合成高真实无益 | 捷径、域错配、任务错位 | 后端／纹样留出及实拍校准 |
| 只加规模有效 | 容量或算力效应 | 等预算机制否定实验 |

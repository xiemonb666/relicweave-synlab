**A6.12 最小实验矩阵与防“拼模型”规则**

| 实验问题 | 最低对照 | 核心观测 | 进入主线标准 |
| 多轮证据审议是否优于一次性精排？ | 静态 relation block；等 FLOPs 深网；普通共享循环。 | Hit/CovRecall、错误转正确／正确转错误、低质与 hard negative。 | 稳定正增益且不是仅由更多计算解释。 |
| 主动证据读取是否优于固定融合？ | 全量固定读、随机读、规则质量优先。 | 相同 token/FLOPs 预算下命中与平均读取量。 | 改善候选同时减少或不增加平均证据预算。 |
| Corrective State 是否真能纠错？ | 残差累加、GRU、scalar gate。 | 先喂误导证据再喂高质量证据，测 wrong->correct 恢复率。 | 恢复率和最终检索同时改善。 |
| Geometry routing 是否有效？ | 任意序列顺序、固定半径图、无几何。 | 几何扰动、姿态变化、局部断口保持、Top-K。 | 对真实姿态／重建变化更稳且 clean guard 不退化。 |
| Persistent Evidence Bank 是否必要？ | 只用 recurrent state；固定 skip。 | 深层后关键局部影响、Evidence Retention/gradient map。 | 关键证据留存与检索指标同时改善。 |
| Contradiction channel 是否减少 hard negative？ | 只有正相似度；普通三类分类头。 | R1/R0 高相似误排、强反证触发率、误拒真邻片。 | hard negative 明显下降且 missing 不被误当冲突。 |
| 动态停止是否分配了正确计算？ | 固定 1/2/4/8 tick。 | tick 与难度、冲突、质量的关系；平均时延与命中。 | 同效果更省算或同预算更高命中。 |

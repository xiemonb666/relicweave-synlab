**G1 实验室要实现的功能与完成标准**

| 模块 | 必须完成的功能 | 交付与边界 |
| 母体与材质 | 批量生成器型、厚度、连续纹样及材料外观 | MotherPack；既可参数生成，也可接入有合法来源的完整体扫描 |
| 碎裂与真值 | 多次碎裂、断面分割、直接邻接和对应关系 | TruthPack；多邻片与多个接触面均支持 |
| 磨损与观测 | 实物损伤、相机成像、部分点云和重建误差分开控制 | ObsPack；能重放单因素及联合退化 |
| 关系与难例 | R0 R1 R2、候选列表、开集、困难负例和证据冲突 | RelationPack；不物化所有两两组合 |
| 主动观测 | 固定可达视角、光照、动作代价和逐步观察 | EpisodePack；仿真动作须对应真实采集可达动作 |
| 训练与诊断 | 数据量质量实验、预训练、真实微调与公平对照 | DatasetRelease与实验报告；真实测试独立 |
| 工程运维 | 预算估算、任务恢复、分片存储、版本缓存和审计 | JobDB Manifest QA；失败不能静默跳过 |

**D8 必测用例**

| 场景 | 预期行为 | 验收证据 |
| 正常手机导入 | ID核对、QA、原子落盘、可查询 | 全链event与原图hash |
| 模糊或高光 | 提示补拍或不足，不静默删除 | QA理由与原失败图 |
| 同图重复导入 | 去重存储并保留引用，不重复证据计数 | source_group和hash |
| 无邻片或不足 | 不强迫给确定拼合 | 输出类型和校准版本 |
| 模型索引不一致 | 阻止推理或回退合格快照 | VERSION_MISMATCH日志 |
| 重复点击补采 | 最多一次任务及动作 | idempotency与seq关联 |
| 新图后旧推理迟到 | 不覆盖最新revision | STALE_REVISION记录 |
| 相机断开 | 文件不算成功，停止或人工接管 | capture失败与恢复 |
| MCU复位或急停 | 停动作，位置无效，重新确认 | 固件状态与前端一致 |
| 磁盘满或文件损坏 | 不提交saved，已有原图不覆盖 | 文件及数据库一致性报告 |
| 服务重启 | 恢复事件和已完成任务，不自动续运动 | 恢复演练录像及日志 |
| 网络断开 | 单机本地继续，外部依赖不阻塞 | 离线启动与任务结果 |

**G2 选用的算法与软件路线**

| 任务 | 首选实现 | 采用原因与升级条件 |
| 器型几何 | 三次B样条或PCHIP剖面 加 旋转体网格 | 尺寸厚度可控；G7给出从剖面到有体积壳体步骤 |
| 低成本碎裂 | 共享非平面切割实体 加 Manifold布尔 | 一张界面切两侧，先保证互补与GT；不是陶瓷真实力学模型 |
| 多块分区 | 共享空间形变下的Voronoi或Power Diagram | 邻接由统一分区生成；禁止每个cell独立噪声变形 |
| 物理碎裂插件 | Breaking Good fracture-modes作者实现 | 作为独立后端；有旧环境及许可约束，先做薄壁资格试验 [GL3] |
| 粗糙场 | 多尺度梯度噪声或频谱合成场 | 控制波长振幅和各向异性；参数以后从真实断口校准 |
| 磨损 | 局部约束平滑 SDF侵蚀 局部布尔缺角 | 三种物理含义分开；整片平滑不能代替断口磨损 |
| 成像 | Blender Cycles路径追踪与确定性几何通道 | RGB追求合理光照；真值几何通道独立，避免去噪污染标签 |
| 点云观测 | 可见三角面光线求交 深度反投影 Open3D | 先生成部分观测；再做有尺度单位的噪声与缺失 |
| 照片重建 | COLMAP SfM 加 PatchMatch MVS | 只在小规模扫描仿真子集实际重建，衡量光照与纹理影响 [GL7] |
| 关系检索 | 分层抽样 加 FAISS或低维索引候选 | 全R2保留，负例按需采；检索特征不读取装配坐标 |
| 持久数据 | Parquet索引 Zarr数值数组 图像tar分片 | 分别匹配列查询、随机数值读取和顺序训练；不是一份巨型文件 |

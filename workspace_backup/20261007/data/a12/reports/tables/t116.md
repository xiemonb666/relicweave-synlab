**G22.1 单机资源配置**

| 资源 | 起步配置 | 优化依据 |
| 几何CPU worker | 2至4个进程 每个底层库1至2线程 | 测峰值RSS与布尔时延；避免进程乘库线程过订阅 |
| 渲染GPU | 1个持久Blender worker | 同片批量渲染多视角，先不启动多个32GB争抢进程 |
| 进程内存 | 给OS留8至12GB 工作任务总RSS约30GB内 | 每worker硬上限通过监测触发降级，不靠swap撑满 |
| GPU显存 | 生成任务目标峰值约24至26GB内 | 留余量给驱动和临时缓冲；训练按实际模型另定 |
| 渲染队列 | 2至4个就绪asset的有界队列 | GPU消费变慢时CPU停止继续堆内存 |
| 训练读取 | 4至8 loader worker 固定预取 | 测解码与数据等待比例，不盲目最大线程 |
| 热缓存 | 初始100至150GB字节预算 | 按LRU清理可重建缓存，冻结资产不被驱逐 |

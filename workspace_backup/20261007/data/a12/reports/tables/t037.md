**A12.11 用合成世界专门验证 CTM 与当前创新机制**

| 创新机制 | 合成受控实验 | 成功信号 | 必须对照 |
| Candidate Hypothesis Evolution | 同一 query 按阶段揭示互相竞争的证据 | 真候选的 belief 轨迹能从低分恢复，错误候选被合理降级 | one-shot scorer、普通共享循环 |
| Quality-Aware Corrective State | 低质量误导证据先出现，高质量证据后出现 | 能纠正旧状态且不过度覆盖高质量历史 | 残差累加、GRU、无质量输入 |
| Contradiction-Aware Revision | 制造“纹样像但几何错”等明确 hard negative | 强反证触发 revision，而 missing 不被误当 negative | 只有相似度的 scorer |
| Geometry-Guided Routing / GCNE | 同一断口改变 token 排列但保留真实几何 | 几何拓扑稳定时性能保持，任意顺序扰动影响更小 | 普通序列邻接、固定 radius graph |
| Persistent Evidence Bank | 中间状态故意压缩或限制 token 预算 | 按需重读能恢复被压缩的关键证据 | 只依赖 final hidden state |
| Adaptive Thinking | easy/hard 样本难度由生成器明确控制 | hard 样本平均 tick 更多且性能/成本更优 | 固定 1/2/4/8 tick |
| Counterfactual Verification | 已知真装配，可预测“若真相邻应出现什么” | 错误候选的 predicted-vs-observed residual 显著更大 | 普通 pair similarity |

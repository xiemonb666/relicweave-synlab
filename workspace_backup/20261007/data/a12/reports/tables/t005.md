**2.2 内部指标合同**

| 指标 | 定义与适用范围 | 目标或判定方式 |
| any@50 | 有邻片查询中至少一名真邻片进入初检50池 | 正常质量内部目标宏值0.95，连同区间报告 |
| Hit@10 | 前10中至少一名库内真邻片 | 比赛准备目标正常质量宏值0.90，95%下界0.85 |
| 低质Hit@10 | 日常低质查询对清晰库，独立母体 | 内部目标0.85，达不到则缩小适用范围 |
| CovRecall@10 | 前10找回库内真邻片的比例 | 与Hit单列，不低于冻结强基线 |
| 新方法主比较 | 同查询同库相对验证集选出的强基线 | 开发起点为增益3个百分点且对象簇CI下界大于0 |
| 干净性能守卫 | 新方法相对同池强基线 | 下降不超过2个百分点，阈值先冻结 |
| 无邻片误导 | mate-absent查询被接受推荐的比例 | 目标不超过5%，95%上界目标不超过10% |
| 有邻片接受覆盖 | mate-present中被系统接受输出的比例 | 目标至少80%，不能靠全拒绝换低风险 |
| 现场流程 | 新查询采集到结果的完整彩排 | 20次至少19次完成，仅作为彩排目标 |
| 工作流价值 | 包括拍摄、补拍、检查的总任务时间 | 中位用时减少30%为内部目标，正确性不恶化 |

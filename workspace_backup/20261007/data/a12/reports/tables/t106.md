**G7.5 多材质与层结构的具体实现**

| 材料族 | 表面及断面差异 | 碎裂与退化实现要点 |
| 粗陶 | 大颗粒 坯体色 孔隙 外表不均匀 | 颗粒场加粗糙面 局部掉粒 孔洞守卫 |
| 细陶 | 较细颗粒 更均匀孔隙与断口 | 短相关长度粗糙场 独立磨圆与侵蚀 |
| 炻器 | 致密颗粒 低孔隙 釉面可选 | 致密断面统计 配合高光和深度失败 |
| 白瓷 | 浅色致密坯体 薄壁 外表釉层 | 小尺度断面 几何薄壁守卫 釉层损伤 |
| 彩瓷 | 瓷基体 加 有分区连续纹样 | 彩绘不能传播到新断面 纹样脱落可控 |
| 施釉陶 | 粗或细坯体 加 独立釉层 | 断面暴露层交界 釉层剥落与坯体分开 |
| 玻璃 | 透明或半透明 高光与光滑断面 | 支持程序贝壳状弯曲切面；理想深度只作oracle，真实式扫描缺测 |
| 石材 | 矿物颗粒 可选层理或色斑 | 各向异性粗糙场 层理方向 缺角与风化 |
| 石膏 | 浅色多孔 粉化与磨蚀 | 孔隙场 颗粒脱落 表面侵蚀 |
| 骨质 | 内外层差异 多孔局部结构 | 有方向性的纹理与切面统计；物理规律待真实校准 |
| 木质 | 连续纤维 年轮 局部涂饰 | 沿纤维偏好切割 不规则撕裂边；不称为真实裂纹求解 |
| 金属 | 反射性 坯体与腐蚀层不同 | 程序切割和腐蚀压力数据；真实塑性撕裂需额外力学后端 |

**9.2 决策与降级**

| 发现 | 项目动作 | 可继续推进 |
| 样品或GT不足 | B先补身份与复核，缩小主测试范围 | A公开原型，C台架，D模拟联调 |
| 手机看不到断口 | 改支撑、取景和照明，测人工观察上界 | 精确硬件需求而非先买多相机 |
| 新方法不胜浅基线 | 保留简单模型，一次定位修复后停止分支 | 数据、产品及补采诊断 |
| DIY图像比手机差 | 修焦点、灯光、振动与ISP，先回手机流程 | 硬件学习和记录成本 |
| 第二相机无新增信息 | 保留单节点，不扩三四路 | 动态灯光和有效角度 |
| RL不胜单步 | 部署规则或单步策略 | 保留RL负结果，不影响比赛闭环 |
| 3D不合格 | 标缺失，走经验证2D | 3D研发单独保留 |
| 现场自动化不稳 | 自动范围收缩，人工补采明确标识 | 保留真实候选与异常日志 |
| 论文机制不足 | 延后投稿，继续做产品和独立证据 | 不以外观包装替代研究贡献 |

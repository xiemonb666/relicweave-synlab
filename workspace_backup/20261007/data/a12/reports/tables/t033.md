**A12.8 训练价值来自“关系规模”，不只来自碎片数量**

| 关系类型 | 生成规则 | 训练价值 | 防捷径要求 |
| R2 真邻接 | 来自同一次碎裂的真实接触面 | 邻接检索正例、局部互补学习 | 允许一个 query 有多个真邻片 |
| R1 同器非邻接 | 同一父器物但无直接接触 | 最重要的结构困难负例之一 | 不能用 object_id 直接判断 |
| 同型异器 | 器型参数接近、尺寸接近但来自不同父器物 | 防止只做器型分类 | 纹样可相似或相同模板 |
| 纹样像/几何错 | 局部纹样高度相似但断口或曲率不兼容 | 训练 contradiction-aware reasoning | 需要显式记录冲突来源 |
| 几何像/纹样错 | 断口局部相似但纹样/整体结构矛盾 | 测试多证据纠错 | 不能把纹样缺失误标为冲突 |
| 严重退化真邻片 | R2 但某一关键证据被强退化 | 训练质量感知、候选恢复与不确定性 | 与 clean twin 成对保存 |

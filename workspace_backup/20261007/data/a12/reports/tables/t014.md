**A6.2 外部论文底层思想与本项目的再推导**

| 思想来源 | 原工作的底层思想 | 不直接搬的部分 | 在 RelicWeave 中重新推导 |
| CTM | 引入与输入维度解耦的内部时间；用神经元历史和同步表征让答案随内部 tick 演化，并支持自适应计算。 | 不把“使用 CTM”本身写成贡献；不照抄分类头。 | 把内部时间改造成候选假设演化时间：每个 tick 显式维护候选 belief、不确定性、支持／反证与证据读取。 |
| Restore-RWKV | 全局传播路径需要适配二维结构；Re-WKV 负责长程关系，Omni-Shift 补局部结构。 | 不搬 H/V 扫描、U-Net 解码器或图像复原头。 | 形成“传播路径应由数据结构决定”的原则：断口沿测地线、边界弧长、曲率主方向或学习到的几何路由传播。 |
| PointRWKV | 局部点云几何与全局关系不是同一种信息，因此用 Local Graph + Global recurrent 分工，并使用多尺度和稳定化。 | 不照抄固定半径图、Graph Stabilizer offset 或完整 PointRWKV block。 | 建立 Fracture Evidence Graph、几何规范化和多尺度断口证据；局部结构先被可靠编码，再交给全局多轮审议。 |
| RWKV-7 | 状态更新不只是衰减累加；generalized delta rule 和动态 gate 允许更灵活的写入、替换与修正。 | 不把 RWKV-7 塞入 CTM，不直接复制语言模型状态公式。 | 形成 Quality-Aware Corrective State：高质量新证据可以保留、写入或纠正由低质量证据形成的旧判断。 |
| Perceiver IO / 可查询潜变量思想 | 复杂输入可由查询从证据集合中按需读取，而不要求全部信息永久压进单一状态。 | 不把潜变量瓶颈当无损压缩。 | Persistent Evidence Bank + Active Evidence Routing：CTM 每轮按当前不确定性回取原始关键证据。 |
| 部分匹配／未匹配机制 | 真实匹配中允许局部区域无对应，不能强制全局一一配对。 | 不把图像关键点对应直接当邻接真值。 | 支持、反证、观察不足、未建立对应四态分开；磨损或遮挡区域允许 unknown。 |

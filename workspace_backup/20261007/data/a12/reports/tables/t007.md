**A2.1 最小函数合同**

| 函数 | 输入 | 输出与约束 |
| encode_observations | 合法ObsPack与encoder_version | 每视图局部特征、全局描述、mask和来源索引 |
| build_evidence | 特征及当前观测版本 | 只读证据快照，保留可回取原图 |
| retrieve | 查询描述、冻结gallery、M | 候选并集与粗分数，不读取GT |
| score_pairs | 查询与候选局部证据 | 邻接分数、支持、冲突、观察充分性 |
| calibrate_output | 分数与合法统计、校准版本 | 接受或待核验或不足，不证明不存在邻片 |
| propose_action | 当前证据与能力表及预算 | 有效动作或STOP或REQUEST_OPERATOR |
| evaluate | 预测、独立GT、冻结协议 | 查询级、母体级指标与失败分解 |

**C9 命令 摄像与文件闭环**

| 命令 | 条件 | 完成语义 |
| HELLO | 不移动 | 返回fw、config、state、capabilities |
| HOME | 急停与限位检查通过 | ACK后DONE，位置有效 |
| MOVE_ABS | 仅READY且目标合法 | ACK仅接收，DONE才到位 |
| SET_LIGHT | 合法灯组与档位 | 回报应用状态，不保证曝光合格 |
| ARM_CAPTURE | 到位稳定且capture_id明确 | 返回CAPTURE_READY |
| CAPTURE_RESULT | PC已收到真实图并校验 | saved或failed及file_hash |
| ABORT | 所有状态 | 停止并锁存原因 |
| RESET_FAULT | 人工确认与条件恢复 | 不自动恢复轨迹，重回零 |

**G29 常见故障与排错顺序**

| 表现 | 优先检查 | 修复与禁止做法 |
| 薄壳变实心 | 母体内壁 口沿 cage SDF分辨率 | 修壳体或后端资格；不能把实心器物算合格陶片 |
| 断口两侧不合 | 是否用了两个不同随机切面 | 重用同C重生成；不能用ICP修错GT后藏原因 |
| 布尔失败或sliver多 | 刀具体水密 相切 噪声过大 尺度 | 检查输入与margin 限粗糙局部精度；记录重试 |
| 二次破碎邻边爆增 | 是否把旧邻边复制给全部子片 | 按旧面裁剪重建GT，不靠距离近自动连边 |
| 磨损没变化 | 是否只改渲染normal或展示mesh | 验证真实实体与高频保留；区分外观和几何 |
| mesh多但信息少 | 采样尺度 平滑 简化 与视图覆盖 | 查看断口局部频谱和coverage，不看总点数 |
| Q0检索近随机 | 坐标单位 标签 feature权限 候选池 | 先验GT与输入再比模型；不直接升级CTM |
| 合成近满分 | 共享坐标 背景 pattern种子 网格编号 | 随机扫描姿态与负控 后端留出，审查捷径 |
| 真实迁移无收益 | 材质裂面纹样和成像分布是否错位 | 校准与任务对齐，再评估扩容 |
| 低质量模型过自信 | quality是否直接读取oracle参数 | 用可观察质量估计加开集校准，不拿GT当传感器 |
| 训练等待IO | 百万小文件 随机读巨大shard 压缩解码 | 分片与bucket 预取 小batch数值chunk |
| 内存或显存溢出 | worker乘线程 堆满队列 SDF多场 | 限流 复用 局部分块 分时GPU，不靠无限swap |
| 恢复数据重复 | 幂等键 commit顺序 shard写者 | 完整状态机和单写者；不手动改成功计数 |

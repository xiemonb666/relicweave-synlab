**A12.7 数据与真值合同：合成数据必须能直接进入现有 ObsPack/FeaturePack 流水线**

| 数据层 | 建议保存内容 | 建议格式/组织 | 泄漏边界 |
| Canonical object | 完整 mesh、材质、纹样、参数化器型 | GLB/PLY + JSON/Parquet 参数 | parent/object 参数仅用于生成与审计，不进入部署模型 |
| Fragment truth | 碎片 mesh、断口面、外表面、边界、原始姿态 | PLY/GLB + NPZ/Parquet | GT pose 只用于 oracle/诊断 |
| Relation graph | R2 邻接、R1 同器非邻接、R0 异器、contact mapping | Parquet/CSV/edge list | split 后不得跨父器物泄漏 |
| Rendered observations | 多视角 RGB、mask、ROI、depth、normal | PNG/JPEG + EXR/NPZ 等数值图 | 渲染器 ID/seed 不得成为标签特征 |
| Degraded geometry | 点云、简化 mesh、法向、曲率和缺失 mask | PLY/NPZ | 每份必须带 degradation recipe |
| Quality vector | 每区域/模态质量字段与可见性 | JSONL/Parquet | 质量标签与邻接标签分离 |
| Provenance | generator_version、seed、recipe、父资产 hash | JSONL manifest | 所有 synthetic 必须可追溯 |

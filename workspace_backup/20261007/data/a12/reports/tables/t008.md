**A3 输入与表示合同**

| 表示 | 建议形状或结构 | 处理规则 |
| images | 每片V张，单张3乘H乘W，V可变 | 不强制每片相同张数，尺寸适配明确记录 |
| local feature map | 每张h乘w乘D0 | mask后抽取有效局部特征，保留原图位置 |
| projected tokens | L乘256作为起点，L可变 | 256是维度，不是固定特征数量 |
| validity mask | L个布尔值 | padding在注意力、池化和损失中排除 |
| metadata | 局部坐标、模态、质量、视图角色 | 没有可信位姿不填写伪造三维坐标 |
| source grouping | 原图与裁剪的共同来源 | 不能把同图裁剪当多份独立证据 |
| geometry optional | 点、法向、单位、坐标系与置信度 | 缺失使用mask，关闭不具备的约束 |

**B3 必须采到的数据**

| 数据 | 必须内容 | 不合格处理 |
| 整片 | 正面、反面、侧壁、轮廓及断口概览 | 缺面标未观察，补拍或限定用途 |
| 断口 | 实际断裂表面、两侧壁、厚度变化、边缘 | 没拍到断裂面不能用于局部关系主测试 |
| 连续线索 | 可见纹饰延续、凹槽、曲率变化和薄壁交界 | 没有该线索如实记，不生成伪纹饰 |
| 质量配对 | 同片清晰、日常和差质量真实观察 | 不以压缩副本代替独立实拍 |
| 重复会话 | 重新装夹后的身份、时间和参数 | 新session，不沿用旧位姿 |
| 相机与尺度 | 镜头、分辨率、曝光信息、标定工况、实测比例尺 | 无尺度仍可2D，关闭毫米几何 |
| 关系证据 | 已确认邻接及难负例、争议记录 | UNKNOWN不用于确定性关系评测 |
| 失败与成本 | 模糊图、高光图、重拍、操作及等待时间 | 不删失败以提高采集成功率 |

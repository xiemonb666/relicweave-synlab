**A12.9 大规模预训练：先学碎片结构，再用真实数据校准域**

| 预训练任务 | 输入/目标 | 希望学到的能力 | 与最终任务关系 |
| Fragment representation | 同一碎片不同视图/退化的一致性 | 视角与轻度退化不变表示 | 提高粗召回稳定性 |
| Same-vessel auxiliary | 同器物 vs 异器物 | 器型/材质/纹样的中尺度先验 | 只能作软先验，不能替代邻接 |
| Adjacency retrieval | query 对完整候选池，多正例排序 | 让真邻片进入 Top-K | 直接对应主任务 |
| Local complementarity | 成对断口局部区域/接触真值 | 学习局部凹凸、边界与表面互补 | 服务精排与物理验证 |
| Degradation consistency | clean twin 与 degraded twin | 鲁棒于质量变化，并估计信息损失 | 服务质量感知与 sim-to-real |
| Quality estimation | 已知退化 recipe -> 区域/模态质量 | 学会区分“冲突”与“看不清” | 服务 Quality-Aware Corrective State |
| Contradiction curriculum | 带明确冲突来源的 hard negatives | 显式建模支持与反证 | 服务 Hypothesis Revision |
| Iterative deliberation pretrain | 分阶段揭示证据、允许早期误导 | 学习候选 belief 的多轮修正 | 服务 Evidence-Deliberative CTM |

**G3 合成数据的种类和计数方式**

| 编号 | 数据产品 | 格式与用途 |
| D01 | 完整母体几何与参数 | mesh数组或GLB加JSON；器型、尺寸、厚度与来源 |
| D02 | 完整母体连续纹样与材质 | 纹理图及程序recipe；含外壁、内壁和新断面材质 |
| D03 | 干净碎片封闭实体 | float32或float64 mesh数组；Q0几何权威资产 |
| D04 | 干净断裂面及对应 | 面片ID、接触patch、面积、采样对应与有效mask |
| D05 | 完整关系图与装配真值 | CSR邻接或边表与SE3；仅TruthPack可读 |
| D06 | 实物磨损与缺角后的实体 | PhysicalPack或recipe；保留损失比例与祖先对应 |
| D07 | 整片多视角RGB | JPEG训练图及小型无损确认集；不是实拍 |
| D08 | 断口局部RGB | 原帧 加 ROI坐标或crop；与整片保持相机关系 |
| D09 | 片体和区域分割mask | PNG或RLE；内外壁、断面、支撑、无效区 |
| D10 | 深度距离与可见性 | float32或明确量化规则的uint16；先区分相机z和光线距离 |
| D11 | 观测法向与真值法向 | 数值数组；真值只能作监督，输入法向由观测几何估计 |
| D12 | 部分点云及颜色 | 分片Zarr或二进制数组；观测空间而非完整表面采样 |
| D13 | 退化后网格与洞 | 可选mesh；保留raw版本，补洞版单独标记 |
| D14 | 估计局部几何描述 | 厚度曲率边界描述加有效性；只从可见观测计算 |
| D15 | 相机标定与采集工况 | K、畸变、分辨率、镜头、灯光和扫描会话 |
| D16 | 质量与覆盖数据 | 可观察质量输入 加 独立oracle诊断；字段权限分离 |
| D17 | R0 R1 R2关系训练行 | Parquet；标签来源、难例类型、损失权重 |
| D18 | 固定检索候选列表 | query池和候选池manifest；支持多个真邻片 |
| D19 | 开放库与无邻片查询 | pool_id与mate_present；无邻片状态相对于候选库 |
| D20 | 配对单因素退化阶梯 | counterfactual_group与recipe；同片共享随机基底 |
| D21 | 实际照片重建子集 | COLMAP工程、重建点云mesh与误差报告 |
| D22 | 可达动作与逐步观测episode | action日志、代价、观察索引、终止与奖励定义 |
| D23 | 受限的模拟出土上下文 | 有缺失冲突和噪声的字段；不能等价母体ID |
| D24 | 反证和机制解释监督 | 哪条证据能排除候选及局部对应；仅有可信构造时生成 |

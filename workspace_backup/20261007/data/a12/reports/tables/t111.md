**G18.2 难例必须有明确构造原因**

| 难例 | 生成方式 | 标签与审计 |
| 同器非邻 | 从当前碎裂事件同母体的非邻片抽取 | R1；共享材质和纹样仍无真实接触面 |
| 相似器型异器 | 参数邻近母体或外观向量相近 | R0；器型近似不能改成同器 |
| 重复纹样 | 同环带非邻片或异器同模板 | R1或R0；表面相似不决定邻接 |
| 几何近似 | 厚度曲率相近或局部面型近似 | R1或R0；索引从可观测描述建立 |
| 单证据冲突 | 纹样支持但断口不支持 或 相反 | 记录冲突来源，反证只在构造可信时监督 |
| 磨损真邻片 | 对R2的一个或两个观测做嵌套损伤 | 历史R2保留，当前对应有效性另标 |
| 多邻片查询 | 完整邻接图含多个R2邻片 | Hit与CovRecall分别计算 |
| 库中无邻片 | 从pool移除该query所有R2邻片 | mate_present为0；仍可保留R1和外观强负例 |

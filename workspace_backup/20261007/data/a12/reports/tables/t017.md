**A6.5 质量、反证与记忆：让模型知道什么可信、什么需要纠错、什么不能遗忘**

| 机制 | 设计要点 | 对任务的直接作用 |
| Feature-level Reliability | 每个区域／模态独立质量向量，进入 read、write、retain、correct gate。 | 低质 3D 不应压过清晰断口 2D；材料低纹理也不应自动判坏图。 |
| Contradiction-Aware Hypothesis Revision | 显式维护支持 E+、反证 E-、观察不足、未建立对应四种状态。 | Hard negative 不再只靠“相似度低一点”，而可由强物理矛盾直接触发候选修正。 |
| Persistent Evidence Bank | 保存原图／局部 patch／合格 3D／来源索引／质量与尺度信息，CTM 每轮可查询。 | 避免第一轮压缩丢掉关键断口细节后后续无法恢复；State != Evidence。 |
| Multi-timescale Evidence Memory | 短时状态保存当前候选竞争，慢状态只保存跨 tick 稳定证据；关键原证据仍在 Bank 中。 | 降低噪声在长循环中累积，同时保留稳定几何线索。 |
| Anti-self-confirmation Replay | 周期性从原证据或强反证池重新读取，而不是只读上一轮已经筛过的状态。 | 防止早期错误候选在循环中不断自证。 |
| Source De-correlation / Provenance | 标记 2D、3D 是否来自同一照片或同一重建，避免将相关证据当独立证据重复加权。 | 提升置信度校准和论文可解释性，避免“同源证据乘法放大”。 |

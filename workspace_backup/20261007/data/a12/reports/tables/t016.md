**A6.4 几何侧创新：让“哪里传播”由断口结构而不是 token 次序决定**

| 候选机制 | 核心定义 | 预期解决的问题 | 主要风险／验证 |
| Geometry Canonicalization | 依据法线、曲率、边界方向和稳定局部特征构造断口自己的局部 canonical frame；必要时学习 SE(3) 修正。 | 扫描姿态、支撑方向、重建坐标系变化导致同一结构表达漂移。 | 局部 frame 在平坦／噪声区不稳定；须和无规范化、PCA／法线基线比较。 |
| GCNE：Geometry-Conditioned Neighborhood Expansion | 邻域权重由测地距离、法线差、曲率差、边界关系和质量共同决定，再扩展局部 token。 | 真实断口邻居不等于序列相邻，也不一定等于固定半径欧氏邻居。 | 过度平滑细小崩边；需做 micro-fracture 保留率和 Top-K 消融。 |
| Adaptive Fracture Evidence Graph | 节点表示局部断口证据，边表示可部署几何关系；边可以含 unknown 与置信度。 | 统一承载局部几何、缺失和不确定性，而不是强制完整图。 | 图构造错误会传播噪声；必须允许未知边并做质量门控。 |
| Multi-scale Fracture Evidence | micro / meso / macro 三层分别描述微小裂纹与崩边、局部断面走势、整体器形与边界。 | 单尺度不能同时保留微细断口和全局器形。 | 尺度冗余和参数膨胀；需单尺度／等参数对照。 |
| Geometry-Guided Recurrent Routing | 内部 tick 的消息路径由当前几何图与候选歧义共同决定，可沿边界弧长、测地线或曲率主方向动态路由。 | 把 Restore-RWKV “结构决定传播路径”的思想改造成任务专属机制。 | 若几何不可靠应自动退化，不得制造伪三维确定性。 |

**3D重建质量强化专项 从“视觉漂亮”升级为“可测量、可重复、可用于匹配”**

| 指标 | 计算方式 | 解释 | 状态 |
| Surface repeat error | 三次重建两两对齐后的对称NN/Chamfer；报告median/P90/P95 | 几何是否可重复，不被单次“漂亮结果”欺骗 | R2c-1前预注册 |
| Normal repeatability | 对应局部法向夹角median/P90 | Physics中的normal complementarity是否可信 | R2c-1前预注册 |
| Boundary repeat error | 断口边界曲线最近点/弧长对齐误差 | 决定轮廓/缺口匹配上限 | R2c-1前预注册 |
| Scale drift | 已知标尺/marker尺寸与重建尺寸偏差 | gap、penetration、thickness能否按真实单位解释 | 每次采集必报 |
| Coverage / confidence | 有效depth/点云覆盖率 + confidence热图 | 区分“没看到”与“确实没有结构” | 每个surface instance必报 |
| Downstream retention | 相同pair在High/Medium/Low质量下的Pair/HN/Hit@0.05保留率 | 最终判断3D质量是否真的影响任务 | 进入R2c-1后主指标 |

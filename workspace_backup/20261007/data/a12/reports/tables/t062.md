**D4 后端API与适配合同**

| 接口 | 输入与目的 | 返回或约束 |
| POST /fragments | 实物登记 | fragment_id与录入状态 |
| POST /sessions | 样片、设备和装夹 | session_id及能力快照 |
| POST /observations/import | 手机原图与capture元数据 | task_id，完成后capture_id |
| GET /observations/{id}/qa | 查询QA和覆盖 | 合格／警告／不合格及理由 |
| POST /queries | 合格capture_ids、model、gallery | query_id和异步任务 |
| GET /queries/{id} | 查询状态 | 状态、版本、实测时间 |
| GET /queries/{id}/results | 候选与证据 | 排名分数类型、支持、冲突、人工状态 |
| POST /queries/{id}/actions/propose | 当前revision及预算 | 动作建议，尚未执行 |
| POST /actions/{id}/execute | revision及idempotency_key | 自动调度或人工任务 |
| POST /actions/{id}/confirm | 人工新图与参数 | 只有文件校验后完成 |
| GET /devices/{id}/capabilities | 台体能力 | axes、ranges、camera、light及校准 |
| POST /tasks/{id}/cancel | 操作取消 | 运动先停止，不假设已安全完成 |
| GET /events | task和最后event_id | 可恢复事件流 |
| POST /reviews | 接受、驳回、待查及理由 | 审核记录，不自动改GT |

**A6.7 高风险高收益创新候选**

| 候选方向 | 核心思想 | 可能形成的论文级问题 | 进入主线的条件 |
| Counterfactual Fragment Verification | 对候选 (q,c) 不只问“像不像”，而先预测“若它们真相邻，下一处应观察到什么几何／纹样／厚度连续关系”，再用真实证据检验。 | 把 matching 从 similarity estimation 提升为 hypothesis -> prediction -> observation -> revision。 | 反事实预测误差能稳定区分 R2 与 hard R1/R0，并在真实低质数据保持增益。 |
| Cross-Evidence Dynamic Consistency | 比较 2D、3D、fracture、texture 在内部时间上的轨迹是否逐步收敛到一致解释。 | 真正邻片是否表现为跨证据动态同步，而 hard negative 表现为持续矛盾？ | 比 final-state 相似度稳定增益，且同步指标能被干预实验验证。 |
| Evidence-specific Synchronization | 不使用通用全神经元同步，而只在有物理意义的证据组之间定义可学习同步。 | 把 CTM 的 synchronization 从通用表征改造为“证据一致性算子”。 | 同预算优于简单 cross-attention／history pooling，并可解释冲突来源。 |
| Learned Evidence Acquisition Policy | 内部策略直接预测“下一轮应该读哪个区域／模态”，训练目标是候选不确定性下降和任务收益。 | 模型能否学会针对不同碎片采用不同思考路径？ | 必须优于固定全读、随机读、质量优先和规则启发式。 |
| Epistemic Learned Stop | 停止不仅看分数 margin，还估计“继续读证据是否可能改变候选”。 | 计算预算能否真正由“还不知道什么”决定？ | 在相同命中率下减少平均 tick，或相同 FLOPs 下提高低质 Hit@K。 |
| Complementarity Prediction / Physical Counterfactual | 从一块断口预测其相邻断口应满足的局部互补场，再用于候选验证。 | 从“描述自己”转向“预测自己的邻片应该是什么样”。 | 预测场在未见母体上可泛化，并优于普通 pair similarity。 |

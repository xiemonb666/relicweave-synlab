**A12.13 MVP 与扩展路线：先把可控性做对，再追求“看起来像真实”**

| 阶段 | 目标 | 交付物 | 进入下一阶段的门 |
| SY0 规范冻结 | 冻结数据 schema、seed/provenance、关系定义和 split | synthetic_manifest、generator_config、最小单元测试 | 重放等级明确；确认物化hash；GT隔离 |
| SY1 生成器 MVP | 参数化器型 + 连续纹样 + 程序碎裂 + 精确邻接图 | 约100母体／2000片；clean与理想可见 | 人工抽检邻接/纹样连续/几何真值正确 |
| SY2 退化平台 | 实现断口、纹样、几何、视角和成像的单因素/联合退化 | SY-Q0_OBS至5配对阶梯 | 声明量可测；不可逆量按规则单调 |
| SY3 大规模生成 | 提高吞吐并扩展关系/hard negative | 2万–10万以上碎片，关系统计和难度分布 | 无 split 泄漏；生成分布和存储可控 |
| SY4 预训练与诊断 | 跑 scaling/quality/CTM 机制实验 | 预训练权重、N×Q 曲面、失败归因报告 | 至少找到可重复的正/负结论，不以单 seed 决策 |
| SY5 Sim-to-Real | 真实数据微调与模拟器校准 | T0至T3及真实误差分布 | 独立真实测试出现可归因收益才升级主线 |

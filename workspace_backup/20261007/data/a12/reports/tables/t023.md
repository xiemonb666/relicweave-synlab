**A9.1 指标手算与失败标签**

| 情况 | 第一项检查 | 处理与禁止事项 |
| 训练损失不降 | 标签、梯度、mask、样本是否进入损失 | 用小训练集定位，不先换大骨干 |
| 训练好验证差 | 母体划分、重复来源、背景与类别分布 | 强化隔离及合理正则，不调确认集 |
| 真邻全部池外 | 初检描述、输入覆盖、M真实大小 | 修初检，不归责精排 |
| R1长期高分 | 是否只学到同器物或纹饰相似 | 增强局部互补和训练R1，不用母体ID过滤 |
| 加视图分数异常升高 | 重复来源、聚合归一化、质量mask | 去重并比较重复图负控 |
| 3D失败 | 尺度、坐标、覆盖、点云有效性 | 回退2D，缺失不填0分 |
| 循环越想越错 | 陈旧状态、监督、停止规则 | 回退静态，记录正确转错误 |
| 补采只提高置信度 | 真实邻片和错误风险是否改善 | 不用自信当奖励 |
| 所有困难查询被拒 | mate-present覆盖 | 重新评风险覆盖，不宣称已可靠 |
| 相机换后下降 | 成像尺度、色彩、标定、设备域 | 先冻结模型配对诊断，不同时训练新头 |

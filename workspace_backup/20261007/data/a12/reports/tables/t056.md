**C7 电气与最终接线**

| 信号组 | 数量 | 接线与启动约束 |
| STEP与DIR | 每个步进轴各2线 | 定时外设输出，满足驱动脉宽及方向建立时间 |
| ENABLE | 每驱动或经验证共享 | 外部上拉或相应电路确保复位禁能 |
| DRIVER_FAULT | 有故障输出时读取 | 按载板拉到合法逻辑电压，锁存故障 |
| HOME及LIMIT | 按轴分配 | 优先常闭开关，去抖并识别断线异常 |
| STOP_FEEDBACK | 1路 | 辅助反馈独立于硬件动力停止 |
| LIGHT1至4 | 4路 | GPIO至逻辑兼容驱动，不带LED负载 |
| SERVO可选 | 1路PWM | 独立额定供电，不从GPIO或小稳压口取动力 |
| UART可选 | RX、TX、GND | 电平匹配，不把5V串口直连3.3V |

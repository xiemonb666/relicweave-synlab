**G6.4 导出数组的形状和空值规则**

| 字段 | 形状和数据类型 | 空值与配套字段 |
| RGB与mask | RGB为H W 3 uint8 区域mask为H W整数 | 缺视图用presence；不塞一张零图假装已拍摄 |
| points | N 3 float32 局部mm坐标 | point_valid为N；空模态可为0 3数组 |
| normals | N 3 float32 观测估计单位法向 | normal_valid为N 另记估计邻域与误差 |
| K与pose | K为3 3 T为4 4 float64或float32 | 相机原始和crop后内参分别存；装配pose隔离 |
| depth | H W float32或定义scale的uint16 | invalid mask独立；无效值不参与loss或反投影 |
| surface_samples | 面ID加重心坐标及局部坐标 | 来源GT与观测对应valid独立，不能混入feature |
| relation | int8枚举R0 R1 R2 UNKNOWN | UNKNOWN通过loss_mask剔除，不编码成R0 |
| quality | 每视图和每区域命名的float32向量 | 每项附valid及来源为OBS_EST或GT_ORACLE |

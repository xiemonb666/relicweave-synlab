**G23.1 按数据访问方式选择格式**

| 数据 | 推荐保存方式 | 具体策略 |
| 真值与元数据 | Parquet加JSON manifest | Parquet按split与有限bucket分区；ZSTD起步，压缩等级实测 [GL6] |
| 权威mesh | 连续数组与offset 或 小规模二进制资产 | 顶点索引材质面源独立数组；PLY或GLB仅导出和检查 |
| 数值观测 | Zarr分块并按需sharding | 点云depth等数值；每shard一个写者，避免多进程写重叠块 [GL8] |
| RGB | 已编码JPEG加tar分片 | 训练顺序读取512MB至1GB shard；确认集保留规定无损版本 |
| mask | RLE或PNG | 整数ID无有损压缩；ROI优先坐标按需crop |
| 退化变体 | 基础资产加recipe | 线上便宜增强；高成本损伤实体与固定测试物化 |
| 编码器特征 | 版本化数值cache | 冻结encoder时复用；变化即失效，不作为权威原始数据 |

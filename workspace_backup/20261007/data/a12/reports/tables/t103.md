**G6.1 六种数据包和最低字段**

| 数据包 | 关键字段 | 职责与读取权限 |
| MotherPack | shape_lineage_id parent_id family params unit material source hash | 母体几何来源；shape_lineage涵盖同模型缩放或微扰衍生 |
| TruthPack | event_id fragments surfaces R2_edges transforms correspondence QA | 完整体装配与关系真值；仅标签生成监督和审计可读 |
| PhysicalPack | fragment_id damage_recipe mesh hash survivor_map lost_volume | 磨损后的真实实体状态；不覆盖clean真值 |
| ObsPack | opaque_sample_id RGB mask camera optional_geometry quality validity | 部署观测同义字段；按白名单向模型提供 |
| RelationPack | query_id candidate_id R_label hard_type surface_gt valid loss_mask | 训练标签及固定池；模型不读取R_label和hard_type作为特征 |
| EpisodePack | initial_obs action_space action_cost observations done reward_spec | 动作环境与日志；奖励计算隔离隐藏GT |

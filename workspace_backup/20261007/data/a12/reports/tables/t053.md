**C5 四区白光与偏振结构**

| 模式 | 灯组与偏振 | 用途 |
| WHITE_DIFFUSE | 多灯均匀白光，灯前偏振可移开 | 轮廓、颜色和基础纹饰 |
| LEFT_GRAZE | 左侧低角度灯 | 断口起伏和裂纹 |
| RIGHT_GRAZE | 右侧低角度灯 | 验证另一方向纹理与阴影 |
| CROSS_POL | 灯前与镜头前偏振轴交叉调整 | 降低部分釉面高光 |
| NORMAL_REFLECT | 普通白光观察 | 保留光泽等材质证据 |

**D3 元数据账本与文件事务**

| 表 | 关键字段 | 约束 |
| fragments | fragment_id、元数据引用、状态 | 对实物身份唯一 |
| capture_sessions | session_id、fragment_id、device、装夹版本 | 换片／翻面新会话 |
| observations | capture_id、path、hash、QA、revision、来源组 | 原图不可覆盖，状态可版本化 |
| galleries | gallery_version、manifest、encoder_version | 冻结快照，可回退 |
| model_registry | model_version、weights_hash、preprocess、schema | 不能混不同编码器索引 |
| queries | query_id、fragment_id、observation_revision、status | 禁止把GT答案作为推理参数 |
| tasks | task_id、type、status、idempotency_key、error | 重复提交不重复执行 |
| predictions | query_id、revision、model、gallery、输出路径 | 每个结果指向准确输入版本 |
| actions | action_id、proposal、执行状态、实际图、成本 | 请求与完成分开 |
| events | event_id、task_id、timestamp、state、payload | 追加写，故障不删除 |
| reviews | 人工核验决定、证据、操作者、时间 | 人工意见与模型排名分离 |

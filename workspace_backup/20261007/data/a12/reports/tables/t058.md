**C11 搭建与验收顺序**

| 测试 | 初始次数或条件 | 留存输出 |
| 回零重复 | 每轴10次 | 重复位置与照片，精度要求按视场确定 |
| 带载循环 | 代表载荷两个完整周期后扩至20任务 | 抖动、清晰度、温升、动作时间 |
| 断电及急停 | 空载先测，确认防坠后带载 | 滑架不坠、固件FAULT、恢复需回零 |
| 重复命令 | 同seq重发、乱序和坏CRC | 最多执行一次或拒绝 |
| 拍摄顺序 | 动作前后时间与文件核对 | 新图不混旧帧，ID与hash正确 |
| 光照 | 全计划曝光、灯光及偏振模式 | 条纹、高光、颜色、区域可辨性 |
| 多节点 | 不同地址、不同ID及依次采图 | 无地址冲突或相机串号 |
| 文件异常 | 磁盘满、相机断开、写坏和掉电 | 不写saved，不继续盲拍 |

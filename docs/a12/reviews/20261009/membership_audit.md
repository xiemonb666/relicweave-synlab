# 新增成员恢复功能：接口—数据—验收交叉审计

审计日期：2026-10-09。范围为指定的 V1.47 主文档/用户源、A12 执行计划、relicweave-synlab 的 A12 合同与验收材料、A12 接口/CLI/角色、运行时代码、相关 tests 和当前 HANDOVER。只读静态检查；没有运行测试、数值计算、训练或实验，也没有改动功能或 Git 状态。此意见供主线程复审。

## 结论

V1.47 已定义“成员恢复”（Level 3）的目标语义：给定查询碎片 q 和冻结图库 G，返回同器成员集合 V_hat(q)；闭集真值 V_G(q) 应由独立、已确认 object membership 的 GT manifest 与 G 求交后排除 q 得到。R1∪R2 是同器关系的物理语义表达，不是通过已标注 R1/R2 边并集构造 V_G 的程序规则；若 q 与候选已确认属于同一器物，即使其 R1/R2 邻接关系未决，该候选仍是 member-positive。只有 object membership 本身未决或 manifest 无法证明闭包时，才不进入 closed-set 主评测。此会员闭合集针对冻结图库，与 pair 邻接闭合独立；它不要求找到库外实物，不等于 R2 直接邻片 TopK，也不承诺全空间装配/修复。

当前 A12 可复用的关系池、R2 检索、固定图库单查询观察 episode、STOP/成本、标签隔离及通用统计原语，均不能证明已有成员头或成员恢复接口。现有评价的真值主轴是 pool.neighbours(q) 的完整历史 R2 集；episode 的 GT coverage 也只算 N_G(q)。成员资格须取自独立的 object-membership GT manifest；R1/R2 未决不能推翻已确认的同器成员身份。因此 A12.22 Whole-Vessel Episode Generator 目前是 V1.47 目标合同，不是代码、资产、CLI 或 A01–A36 已验收能力。缺项按未实现/未验收处理。

## 建议作为最小增补的合同条款

1. **明确独立成员真值与闭集资格**：对每个 q,G 保存离线、独立于 pair adjacency labels 的 object-membership GT manifest、来源/版本与闭包状态；从该 manifest 与冻结 G 求交并排除 q，派生 V_G(q)。R1/R2 是 pair 关系的物理语义表达，不得用已标注 R1/R2 边并集代替成员 manifest。若同器身份已确认而邻接未知，候选仍是 member-positive；只有 object membership 本身未决或 manifest 无法证明图库闭合时，才排除 closed-set 主评测。成员闭合集与 pair 邻接闭合分别判定。
2. **拆开 world generation 与 capture episode**：定义 MemberEpisodeSpec/生成函数控制母体与图库规模、同器成员数、R1/R2 构成、困难负例、质量/退化/材料相似度、查询采样和预算；分别定义 truth-side member-manifest asset、typed adjacency asset 和 inference-side member result asset/schema。现有 episode_trace 继续只表示观察动作轨迹。
3. **固定线上与离线字段边界**：推理/API 仅接受授权 Obs、冻结 gallery 引用及公开成本、预算和停止策略定义；对象 ID、闭包标签、完整关系图、oracle 状态与 GT 派生奖励只进入离线 truth/training/evaluator，奖励不得作为部署观测输入。成员候选解释/provenance 可输出，但不得泄漏 hidden ID/答案。
4. **定义结果与停止**：member output 为全图库候选的同器集合/拒绝/UNKNOWN/补采状态，并记录阈值版本、假设、每轮新增/移除成员、证据、预算消耗、stop_reason；预算耗尽或无新证据必须保留未闭合状态，不能默认成功。
5. **冻结评价合同**：登记非空、空、双空三种 hand-computed case，按 V1.47 规定 P/R/F1/false inclusion/abstention；先 object 内 query 等权，再 object macro；对独立 source cluster 做 CI。固定单图库结果只支持 conditional-on-gallery 主张。
6. **先冻结 baselines 与 controls**：最小静态成员集预测器及 dev 阈值；B1 Scalar Feedback 单列为关系反馈消融；R2 oracle 和完整 member truth 只能离线。对 privileged R2 control 匹配 candidate/context/budget 并做 shuffle/equal-context 与 predicted/corrupted-R2 controls。
7. **补充验收映射**：新建 A37/专门 A12.22 条目（或在 A29/A30/A31/A32/A19 下新增不混淆的子项），明确代码/API/asset role/CLI/test fixture 和不同 profile 状态。最低验收覆盖：R1-only 成员不可漏判为空、R2 不传递、query 排除、UNKNOWN 保持未知、开世界排除主闭集分母、所有空集语义、object macro 与 source-cluster CI、GT 隔离和 generator 泄漏、hypothesis/stop/budget 可复现。

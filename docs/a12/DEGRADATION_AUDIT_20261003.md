# Degradation implementation audit — 2026-10-03

## Finding

The current registry exposes 31 axes through `synlab.degrade.api.apply_axis`, but that is not evidence that the A12 experiment pipeline materializes all of them. This audit exercised four axes at levels 0 / weak / strong on synthetic fixtures. It found real measurable responses for P02, P05, P06, and I03, alongside three concrete contract failures: P06's realized coverage runs opposite to the declared coverage parameter, P05/P06 discard appearance annotation channels and cannot be chained, and the P02 production `apply_damage` route reports a passing result while its assembled component fails the watertight check. None of these synthetic runs validates archaeological realism or real-phone calibration.

The user's end goal includes convincing simulated artifacts and shards, controllable material aging/corrosion/wear and pattern/color loss, phone/DIY capture error, and labels that remain usable by RelicWeave. A12 should support real-neighbor retrieval, evidence rejection, reacquisition, and STOP decisions; these axis probes do not replace or certify those A12 duties.

### Failures and unknowns

1. **Appearance channels are dropped, so P05/P06 do not compose.** Input appearance included `interface_region`, `pattern_region`, `texel_albedo`, `texel_area_mm2`, `texel_layer`, `texel_positions`, `texel_roughness`, and `texel_substrate_albedo`. P05 returns only `paint_mask_removed`, `paint_mask_retained`, and `texel_albedo`; P06 returns only `dirt_mask`, `texel_albedo`, and `texel_roughness` (`synlab/physical/operators.py:751-791` and `794-844`). `_PhysicalAxis._apply` replaces the bundle's appearance with that result (`synlab/degrade/axes.py:399-451`). The measured P05→P06 chain fails `NA_NOT_APPLICABLE` due to missing `texel_area_mm2` / `texel_positions`; reverse P06→P05 fails due to missing `texel_substrate_albedo` / `texel_area_mm2` / `texel_positions`. See [`appearance_chain_checks.csv`](../../tmp/review_20261003/implementation/degradation_audit/appearance_chain_checks.csv). The synthetic fixture does not carry `clean_truth`, so this proves lost annotation channels and broken appearance chaining, not actual loss of historical truth on production assets.

2. **P06 coverage direction disagrees with its parameter name and documentation.** The operator computes a quantile at `1 - coverage`, then selects `values <= threshold` (`synlab/physical/operators.py:806-809`); `threshold_for_fraction` itself returns the `1 - fraction` quantile (`synlab/physical/fields.py:414-424`). The observed 0.2→0.7939 and 0.8→0.2041 responses confirm the inversion in this fixture. Correctness should be defined on covered physical area, not texel count alone, because texel areas can vary.

3. **P02 route-level physical audit disagrees with final QA.** The direct `apply_axis` probe's narrowband operator measurement reports `watertight=1`. The separate production route `physical.api.apply_damage → physical.operators.run_damage` selects declared narrowband for P02 (`synlab/physical/operators.py:1149-1176`) and its operator measurement also reports `watertight=1`, yet the assembled component mesh is non-watertight with one 3-edge boundary loop of 2.8284 mm diagonal, too large for the configured 0.001 mm pinhole closure. The `physical_audit.checks.watertight.pass` and `physical_audit.status` are false, `assembly.watertight_bodies=0`, while `physical_result_qa.status` is `PASS` because `realized=true`. This is a single small synthetic-box finding; confirm the intended open/closed-surface contract before generalizing. The audit detail is in `appearance_probe.json` under `p02_production_route`.

4. **I03's status field can overstate annotation work.** `I03._apply` rewrites sensor frames (`synlab/degrade/axes.py:989-1033`) but does not itself recompute truth. For operators declaring label invalidations, `synlab/degrade/api.py:381-392` returns `RECOMPUTED` solely when `import synlab.truth` succeeds unless result metadata sets a status. The probe showed `I03` nonzero levels with `label_status=RECOMPUTED`, but no recomputation artifact/call is recorded. Treat this as a status/provenance contract defect, not proof that labels are wrong.

5. **Color-aging/corrosion capability is missing or unintegrated.** In the current registry P05 is paint removal, P06 dirt appearance, and I05 white balance/camera color shift. None is a calibrated material color-fade/patina/corrosion operator. A separate `synlab/degrade/wear.py` model creates scalar soil/patina maps (`1164-1208`) and `apply_wear` (`1217+`), with `burial_years=300` explicitly marked candidate provenance (`755`, `795-799`) and used in a wear scale (`1066-1067`). It is not RGB material fading, and repository search found no registry/pipeline integration through `wear_apply`; this audit did not execute it. Its candidate calendar parameter is not a physical calibration.

## Calibration, tests, and provenance

All four probed axes reported `UNCALIBRATED`. No real artifact capture, controlled abrasion/corrosion sample, camera-reference capture, phone scan, or independently measured geometry appears in this audit. Monotonicity is expected only where the parameter is defined as an ordinal amount and measurement has a comparable area/geometry denominator; discrete masks and spatially frozen fields may create local ties. `P05` retained paint fraction decreases as intended; `I03` measured noise increases as intended. P06 coverage fails its expected direction. P02 recession is monotonic across the two nonzero levels on this fixture, while unrelated ROI drift need not be strictly monotonic on a discretized mesh.

## Bounded implementation routes for the main agent to choose

1. **Restore appearance/annotation continuity.** Define a required-channel contract for appearance payloads; make P05/P06 retain unchanged channels; add a small `clean_truth` fixture and verify chaining, visible-label invalidation/recomputation, and truth reference preservation before considering wider recipes.
2. **Align P06's declared coverage.** On fixed field and area-weighted texels, test levels 0–4 against realized covered-area fractions; repair the threshold/selection contract so higher requested coverage cannot produce lower measured covered area.
3. **Reconcile P02 final QA.** Decide whether resulting P02 mesh components must be watertight. If yes, make final physical QA fail closed on the post-assembly watertight audit; if an open surface is allowed for this route, represent that contract explicitly rather than reporting an unqualified `PASS`. Validate on one small controlled fixture before any production run.
4. **Add material chromatic aging only with bounded claims.** Integrate a separate patina/corrosion/color-fade axis that preserves spatial masks and source annotations, expose ordinal intensity levels without claiming calendar-year calibration, then calibrate against a small controlled material/capture set before using historical-time labels.
5. **Make sensor/label status evidence-based.** Record the actual label recomputation artifact/call or return an explicit pending/invalidated status; later calibrate I03 against captured phone/DIY imagery and reconstruction errors.

These are candidate routes for main-agent scope selection; no production code or frozen experiment config was changed in this audit.

# 现实效果验收依据（2026-10-03）

本文给 VF / PG / A12 的现实性审查提供分层门槛。它不是“看起来像陶瓷”的评分表：几何、求解物理、材料来源和实物形貌必须各有可复核证据。没有来源或测量时标记 `UNKNOWN` / `PENDING`，不填入通用陶瓷粗糙度、强度或壁厚阈值。

## 当前证据能支持什么

- 当前 VF 预览是一只中空、带把手、带四道色带的器物。截面图能检查腔体和可见壁面；实现账本同时记录了分段轮廓的 C0 接点、把手根部过渡突兀、平滑度和历史器型未验证。已报告的 STEP/网格与轮廓抽样结果是有限样本，侧壁及平底的局部 4 mm 检查不是全器最小壁厚证明。
- 当前 ornament 是绘制色带，几何 relief 为零；配方和色彩没有通过历史风格或颜料/釉层标定。表面纹理应当依光线、釉层、胎体和底层结构变化，不能把一个颜色/粗糙度值称为真实材质。
- 当前 PG 图只表达材料点、损伤和完整键图状态。图注明确写了 `geometry surface reconstruction: absent`、`UNVALIDATED_PROTOTYPE`；它既没有裂面网格，也没有逐步裂纹事件链，不能作为陶瓷断口形貌通过的证据。
- 已有 wear 代码按口沿、底部、釉层、崩口、微裂纹和沉积等机制分场，但其实际磨损量和历时映射仍是候选值。当前没有同批真实陶瓷的受控磨损前后对照。VF 账本中的 `E` / `Gc` 等力学数值是说明性未验证输入；这些数值作为候选输入保留，实际材料标定状态仍为 `UNKNOWN` / `UNVALIDATED`。

## 四层验收

| 层 | 通过需要看到的证据 | 当前判定 |
|---|---|---|
| **数学几何** | 每类器型由自身轮廓/局部尺寸参数定义；只缩放同一网格不算新增器型。声称圆滑的轮廓在连接处须有连续切线，并报告接点曲率变化；用全表面厚度场检查口沿、底、弯曲壁和把手根部，记录测量方向/覆盖率/最小值与分位数。CAD、STEP、网格之间报告带单位的误差，并用加密或重采样确认结果稳定。宣称真实 relief 时，必须在可测高度/网格几何中存在 relief，而不只是着色或法线贴图。 | **PENDING**：有一个器型和局部几何检查；C0 接点、把手根部及全局壁厚仍待证。 |
| **数值物理** | 裂纹由已声明的载荷、缺陷、材料参数和断裂律产生；先预设平面切开再叠加统一噪声不算通过。报告载荷—位移、裂纹起点/路径、能量收支、时间步/网格或粒距收敛，以及可重建的配对裂面。将方向性断口标记、局部粗糙变化、孔隙/晶粒作用和过程区尺度关联到裂纹前沿及材料微结构；只能在实际分辨率支持的尺度上作判断。允许起裂附近出现较平滑的镜面区，不能要求整片同样粗糙。NIST 对多晶陶瓷指出，微结构本身可能令镜面区粗糙、令镜面—雾状边界难以辨认；孤立微结构台阶也不等于整体裂纹传播标记（SP 960-16e2，附录 D，D-2）。 | **PENDING**：PG 目前没有裂面重建；点/键状态不能代替物理断裂验证。 |
| **来源与材料标定** | 为材料批次和试样记录组成/烧成或来源、密度、孔隙/晶粒信息（可得时）、测试方法、单位、误差及每个参数的 provenance/status（实测、可核文献、推导、候选、未知）。输入参数有明确数值时保留原数值并记录来源/状态；没有实测或可核文献依据时，将实际材质参数或校准状态标为 `UNKNOWN` / `UNVALIDATED`，不把已有候选数值改成空值。图像、watertight 或示例参数不能证明实际材料已校准。 | **PENDING**：当前数值可作为带状态的候选输入；实际陶瓷材质的校准尚未建立。 |
| **实物形貌与视觉** | 以来源可核的实物图像/扫描比较轮廓、口沿、足部、把手和装饰位置；对照照片须记录视角、透视、光源和比例尺。颜色应在固定光源/色卡下检查；分别表示胎体、釉/化妆土/颜料、表面浮雕和光泽。断口至少有整器定位和匹配断面的近景；磨损要用同一表面的前后测量及明确的作用条件，分别观察接触磨蚀、崩口、釉层损失、微裂纹和沉积。 | **仅限展示**：当前四带图能说明预览链路显示了色带，不能说明器型多元、颜色/釉层真实、浮雕真实、断口真实或多年磨损真实。 |

粗糙度没有可直接套用于所有陶瓷的单一通过值。NIST 对玻璃和陶瓷的断口分区依材料、显微结构和裂纹速度而变；其硅玻璃 AFM 个案甚至在镜面区的一段应力强度范围内观测到 RMS 粗糙度下降。该个案只说明不应设一个普适粗糙度门槛，不能把其中数值当作陶瓷标准。评价应报告尺度、采样分辨率、方向性和测量不确定度，并与同类材料/工艺的实测参考比较。

## 首个小型参考对照

1. **器型与装饰（只评外观/轮廓）**：The Met 的 Minoan terracotta cup（07.232.32）记录为高 7.8 cm、直径 11.4 cm，深色绘于浅色胎体，外侧四道带纹并有波线；其图像标为 Public Domain。另用不同形状的朴素 Etruscan olpe（03.24.29；高 10 cm）作器型对照，不把任一对象当作复刻目标。先在校正透视并统一比例的视图中比较轮廓、口沿/底足比例、把手根部和带纹落点；单张照片不用于推断内壁厚度或材料力学。
2. **断裂物理（单一材料、一个小试验系列）**：选来源和烧成批次明确的同批小陶瓷试样，保留几何与缺陷记录，做有载荷记录的弯曲断裂；测量载荷—位移、起裂位置，并对匹配的两侧断面作全貌及局部三维/显微记录。用同一几何、载荷和带 provenance/status 的材料输入跑本机小模型，比较起裂、路径、配对面和测量尺度内的形貌；只有对应试验方法确实给出时才将 `E` / `Gc` 标成实测校准值，候选数值继续保留并标示未验证。试样不足以建立统计区间时只报单次结果，不宣称材料通用性。
3. **多轴磨损（同一基准、分机制施加）**：对一件可牺牲的同类试片做磨损前基准扫描；分别在独立小区域施加已记录的口沿/接触磨蚀、一次受控边缘冲击、以及可见釉层损失机制，再做一组组合条件。复测各区域的高度/体积变化、边缘轮廓和外观变化；沉积/污渍单独记录为表面附着或颜色变化，不计作胎体材料损失。实际载荷、循环数、介质和测量误差是试验输入，日历年数到损伤量的换算暂不建立。

本机算法小验证可先用保留原值并明确标为候选的数值输入，检查数据链、单位、配对面和量测脚本；这只能验证算法和数值流程，不能声称实际陶瓷材料已校准。同批实体试验是建立物理真实性的最高可信度后续证据，不是本机算法小验证的先决审批阻塞。PNG 相似度、watertight、连通分量或单个总体粗糙度数值都不能跨过上述层级。
